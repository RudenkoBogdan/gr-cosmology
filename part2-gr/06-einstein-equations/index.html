    6. Уравнения Эйнштейна¶

    В главе 5 мы узнали, как пробные тела движутся в заданной метрике. Теперь — вторая половина ОТО: как материя определяет метрику. Ньютоновская теория даёт подсказку — уравнение Пуассона \(\nabla^2\Phi = 4\pi G\rho\), — и наша задача найти его тензорное обобщение. Мы проделаем это двумя путями: эвристически, следуя Эйнштейну, и из принципа наименьшего действия, следуя Гильберту. Затем обсудим космологическую постоянную, проверим ньютоновский предел и сформулируем энергетические условия — ограничения на «разумную» материю, которые понадобятся в теоремах о чёрных дырах и в космологии.

    6.1. Тензор энергии-импульса¶

    Источником гравитации в ОТО является не масса, а тензор энергии-импульса (ТЭИ) \(T_{\mu\nu}\), введённый в главе 1. Напомним его смысл: \(T^{\mu\nu}\) — поток \(\mu\)-й компоненты 4-импульса через поверхность \(x^\nu = \text{const}\). В частности, \(T^{00}\) — плотность энергии, \(T^{0i}\) — плотность импульса, \(T^{ij}\) — тензор напряжений. ТЭИ симметричен.

    Идеальная жидкость

    Идеальная жидкость с плотностью энергии \(\rho\) и давлением \(p\) в собственной системе отсчёта, движущаяся с 4-скоростью \(U^\mu\), имеет

    \[\begin{equation} T_{\mu\nu} = (\rho + p)\,U_\mu U_\nu + p\, g_{\mu\nu} . \label{eq:perfect-fluid} \end{equation}\]

    В системе покоя (в локально инерциальных координатах) \(T_{\mu\nu} = \mathrm{diag}(\rho, p, p, p)\).

    Частные случаи: пыль (\(p = 0\)), излучение (\(p = \rho/3\), след \(T = 0\)), энергия вакуума (\(p = -\rho\), \(T_{\mu\nu} = -\rho\,g_{\mu\nu}\)). В космологии удобно уравнение состояния \(p = w\rho\).

    Вычисления

    Шаг 1. Система покоя. \(U^\mu = (1,0,0,0)\), \(U_\mu = \eta_{\mu\nu}U^\nu = (-1,0,0,0)\). Из \(\eqref{eq:perfect-fluid}\):

    \[ T_{00} = (\rho+p)(-1)^2 + p\,\eta_{00} = \rho + p - p = \rho, \qquad T_{0i} = 0, \qquad T_{ij} = p\,\delta_{ij} . \]

    Шаг 2. След. \(T = g^{\mu\nu}T_{\mu\nu} = (\rho+p)U^\mu U_\mu + p\,\delta^\mu_\mu = -(\rho+p) + 4p = 3p - \rho\).

    Шаг 3. Частные случаи. Излучение: \(T = 3\cdot\tfrac\rho3 - \rho = 0\). Вакуум: \(p = -\rho\) убивает первый член, \(T_{\mu\nu} = -\rho\,g_{\mu\nu}\) — одинаково в любой системе отсчёта.

    Другие важные примеры:

    \[\begin{equation} T_{\mu\nu}^{\rm (EM)} = F_{\mu\lambda}F_\nu{}^\lambda - \frac14 g_{\mu\nu}F_{\lambda\sigma}F^{\lambda\sigma}, \qquad T_{\mu\nu}^{(\phi)} = \nabla_\mu\phi\nabla_\nu\phi - g_{\mu\nu}\left(\frac12 g^{\lambda\sigma}\nabla_\lambda\phi\nabla_\sigma\phi + V(\phi)\right). \label{eq:tei-fields} \end{equation}\]

    По принципу минимальной связи \(\S\)5.4 закон сохранения имеет вид

    \[\begin{equation} \nabla_\mu T^{\mu\nu} = 0 . \label{eq:conservation} \end{equation}\]

    Это не глобальный закон сохранения

    В искривлённом пространстве \(\eqref{eq:conservation}\) не превращается в интегральный закон: \(\nabla_\mu T^{\mu\nu} = \frac{1}{\sqrt{-g}}\pd_\mu(\sqrt{-g}T^{\mu\nu}) + \Gamma^\nu_{\mu\lambda}T^{\mu\lambda}\), и второе слагаемое описывает обмен энергией-импульсом с гравитационным полем. Глобальная энергия определена только при наличии вектора Киллинга или на асимптотике плоского пространства.

    Вычисления

    Шаг 1. Определение. \(\nabla_\mu T^{\mu\nu} = \pd_\mu T^{\mu\nu} + \Gamma^\mu_{\mu\lambda}T^{\lambda\nu} + \Gamma^\nu_{\mu\lambda}T^{\mu\lambda}\) (по \(+\Gamma\) на каждый верхний индекс).

    Шаг 2. Свёртка символов. \(\Gamma^\mu_{\mu\lambda} = \tfrac12 g^{\mu\sigma}(\pd_\mu g_{\lambda\sigma} + \pd_\lambda g_{\mu\sigma} - \pd_\sigma g_{\mu\lambda})\). Первый и третий члены сокращаются: после переименования \(\mu\leftrightarrow\sigma\) в третьем \(g^{\mu\sigma}\pd_\sigma g_{\mu\lambda} = g^{\sigma\mu}\pd_\mu g_{\sigma\lambda}\) — то же, что первый. Остаётся

    \[ \Gamma^\mu_{\mu\lambda} = \tfrac12 g^{\mu\sigma}\pd_\lambda g_{\mu\sigma} = \tfrac12\pd_\lambda\ln|g| = \pd_\lambda\ln\sqrt{-g}, \]

    по формуле Якоби \(\pd\ln\det M = \mathrm{tr}(M^{-1}\pd M)\).

    Шаг 3. Сборка.

    \[ \pd_\mu T^{\mu\nu} + \frac{\pd_\lambda\sqrt{-g}}{\sqrt{-g}}T^{\lambda\nu} = \frac{1}{\sqrt{-g}}\pd_\mu\bigl(\sqrt{-g}\,T^{\mu\nu}\bigr), \]

    откуда формула в тексте. Первый член — дивергенция, интегрируемая по теореме Гаусса; член \(\Gamma^\nu_{\mu\lambda}T^{\mu\lambda}\) — нет (у \(T\) два индекса, а не один).

    Для пыли \(\eqref{eq:conservation}\) даёт сохранение числа частиц и уравнение геодезической \(U^\mu\nabla_\mu U^\nu = 0\): движение материи следует из уравнений поля. Для идеальной жидкости проекция на \(U_\nu\) даёт закон сохранения энергии \(U^\mu\nabla_\mu\rho + (\rho + p)\nabla_\mu U^\mu = 0\), а проекция на ортогональное к \(U\) подпространство — релятивистское уравнение Эйлера.

    Вычисления

    Шаг 1. Дивергенция. Из \(T^{\mu\nu} = (\rho+p)U^\mu U^\nu + p\,g^{\mu\nu}\) и \(\nabla g = 0\):

    \[ \nabla_\mu T^{\mu\nu} = U^\nu\nabla_\mu\bigl((\rho+p)U^\mu\bigr) + (\rho+p)\,U^\mu\nabla_\mu U^\nu + g^{\mu\nu}\nabla_\mu p . \]

    Шаг 2. Полезное тождество. \(U_\nu U^\nu = -1\) ⇒ \(0 = \nabla_\mu(U_\nu U^\nu) = 2U_\nu\nabla_\mu U^\nu\).

    Шаг 3. Проекция на \(U_\nu\). \(U_\nu U^\nu = -1\), второй член зануляется по Шагу 2:

    \[ -\nabla_\mu\bigl((\rho+p)U^\mu\bigr) + U^\mu\nabla_\mu p = -U^\mu\nabla_\mu\rho - U^\mu\nabla_\mu p - (\rho+p)\nabla_\mu U^\mu + U^\mu\nabla_\mu p = 0, \]

    т. е. \(U^\mu\nabla_\mu\rho + (\rho+p)\nabla_\mu U^\mu = 0\).

    Шаг 4. Ортогональная проекция. \(h^\sigma{}_\nu = \delta^\sigma_\nu + U^\sigma U_\nu\) (\(h^\sigma{}_\nu U^\nu = 0\)). Первый член уничтожается, второй не меняется (он уже ортогонален \(U\) по Шагу 2):

    \[ (\rho+p)\,U^\mu\nabla_\mu U^\sigma = -\left(g^{\sigma\mu} + U^\sigma U^\mu\right)\nabla_\mu p . \]

    Шаг 5. Пыль (\(p = 0\)): Шаг 4 даёт \(U^\mu\nabla_\mu U^\sigma = 0\) — геодезическая; Шаг 3 — \(\nabla_\mu(\rho U^\mu) = 0\), сохранение числа частиц (\(\rho = mn\)).

    6.2. Эвристический вывод¶

    Ищем уравнение вида \(\mathcal{G}_{\mu\nu}[g] = \kappa\,T_{\mu\nu}\), обобщающее \(\nabla^2\Phi = 4\pi G\rho\). Поскольку \(\rho \approx T_{00}\), а \(\Phi\) связан с \(g_{00}\) соотношением \(g_{00} = -(1 + 2\Phi)\) (гл. 5), левая часть должна быть:

    1. симметричным тензором ранга (0,2);
    2. построенным из метрики и её производных не выше второго порядка, линейно по вторым;
    3. бездивергентным, \(\nabla^\mu \mathcal{G}_{\mu\nu} = 0\), — иначе противоречие с \(\eqref{eq:conservation}\).

    Из вторых производных метрики тензорно строится только тензор Римана (глава 4). Свёртки дают \(R_{\mu\nu}\) и \(R g_{\mu\nu}\). Первой попыткой Эйнштейна было \(R_{\mu\nu} = \kappa T_{\mu\nu}\), но из свёрнутого тождества Бьянки

    \[\begin{equation} \nabla^\mu R_{\mu\nu} = \frac12\nabla_\nu R \label{eq:bianchi} \end{equation}\]

    следует \(\nabla_\nu T = 0\), т.е. постоянство следа \(T\) во всём пространстве-времени — физически недопустимо. Комбинация, у которой дивергенция тождественно равна нулю, — это тензор Эйнштейна

    \[\begin{equation} G_{\mu\nu} = R_{\mu\nu} - \frac12 R\, g_{\mu\nu}, \qquad \nabla^\mu G_{\mu\nu} = 0 . \label{eq:einstein-tensor} \end{equation}\]
    Вычисления

    Шаг 1. Почему \(R_{\mu\nu} = \kappa T_{\mu\nu}\) не годится. Берём дивергенцию и применяем \(\eqref{eq:conservation}\) и \(\eqref{eq:bianchi}\): \(\kappa\nabla^\mu T_{\mu\nu} = \nabla^\mu R_{\mu\nu} = \tfrac12\nabla_\nu R\), т. е. \(\nabla_\nu R = 0\). След уравнения: \(R = g^{\mu\nu}R_{\mu\nu} = \kappa T\). Значит, \(\nabla_\nu T = 0\).

    Шаг 2. Дивергенция \(G_{\mu\nu}\). Метрика выносится из-под \(\nabla\):

    \[ \nabla^\mu G_{\mu\nu} = \nabla^\mu R_{\mu\nu} - \tfrac12 g_{\mu\nu}\nabla^\mu R = \tfrac12\nabla_\nu R - \tfrac12\nabla_\nu R = 0 . \]

    Теорема Лавлока (1971) утверждает, что в четырёх измерениях \(G_{\mu\nu}\) и \(g_{\mu\nu}\) — единственные тензоры, удовлетворяющие условиям 1–3 (без требования линейности по вторым производным). Итак, \(G_{\mu\nu} = \kappa T_{\mu\nu}\), а в 6.5 мы найдём \(\kappa = 8\pi G\).

    Уравнения Эйнштейна

    \[\begin{equation} R_{\mu\nu} - \frac12 R\,g_{\mu\nu} = 8\pi G\,T_{\mu\nu} \qquad \left(\text{с } c:\ \frac{8\pi G}{c^4}\,T_{\mu\nu}\right). \label{eq:efe} \end{equation}\]

    Это 10 нелинейных уравнений в частных производных второго порядка для 10 компонент \(g_{\mu\nu}\). Однако четыре тождества Бьянки \(\eqref{eq:einstein-tensor}\) делают независимыми лишь 6 из них — ровно столько, сколько нужно: четыре компоненты метрики отражают свободу выбора координат (калибровочная инвариантность ОТО).

    Свернув \(\eqref{eq:efe}\) с \(g^{\mu\nu}\) (в четырёх измерениях \(g^{\mu\nu}g_{\mu\nu} = 4\)), получаем \(-R = 8\pi G\,T\). Подставляя обратно, приходим к эквивалентной форме с обращённым следом:

    \[\begin{equation} R_{\mu\nu} = 8\pi G\left(T_{\mu\nu} - \frac12 T\,g_{\mu\nu}\right). \label{eq:efe-trace-reversed} \end{equation}\]
    Вычисления

    Шаг 1. След. Умножаем \(\eqref{eq:efe}\) на \(g^{\mu\nu}\): \(g^{\mu\nu}R_{\mu\nu} = R\), \(g^{\mu\nu}g_{\mu\nu} = 4\), \(g^{\mu\nu}T_{\mu\nu} = T\):

    \[ R - \tfrac12 R\cdot 4 = -R = 8\pi G\,T \quad\Longrightarrow\quad R = -8\pi G\,T . \]

    Шаг 2. Подстановка. \(R_{\mu\nu} = 8\pi G\,T_{\mu\nu} + \tfrac12 R\,g_{\mu\nu} = 8\pi G\,T_{\mu\nu} - 4\pi G\,T g_{\mu\nu}\) — это \(\eqref{eq:efe-trace-reversed}\).

    Проверка. След правой части: \(8\pi G(T - \tfrac12 T\cdot4) = -8\pi G T = R\). В вакууме \(T_{\mu\nu} = 0\) ⇒ \(T = 0\) ⇒ \(R_{\mu\nu} = 0\).

    В вакууме \(T_{\mu\nu} = 0\), и уравнения сводятся к

    \[\begin{equation} R_{\mu\nu} = 0 . \label{eq:vacuum} \end{equation}\]

    Это не означает плоского пространства: тензор Вейля (бесследовая часть Римана) может быть отличен от нуля. Именно он описывает поле вне звёзд (глава 7) и гравитационные волны (глава 9).

    6.3. Действие Гильберта¶

    Более систематический путь — принцип наименьшего действия. Единственный скаляр, содержащий не выше вторых производных метрики, — скаляр Риччи \(R\). Инвариантный элемент объёма — \(\sqrt{-g}\,\d^4x\), \(g = \det g_{\mu\nu}\). Действие Эйнштейна — Гильберта:

    \[\begin{equation} S = \frac{1}{16\pi G}\int \sqrt{-g}\,R\;\d^4x \;+\; S_M[g, \psi] . \label{eq:hilbert-action} \end{equation}\]

    Варьировать удобно по обратной метрике \(g^{\mu\nu}\). Запишем \(\sqrt{-g}R = \sqrt{-g}\,g^{\mu\nu}R_{\mu\nu}\); тогда

    \[ \delta(\sqrt{-g}\,R) = \sqrt{-g}\,R_{\mu\nu}\,\delta g^{\mu\nu} + R\,\delta\sqrt{-g} + \sqrt{-g}\,g^{\mu\nu}\delta R_{\mu\nu} . \]

    Нужны три факта.

    1. Вариация детерминанта. Из \(\delta\ln\det M = \mathrm{tr}(M^{-1}\delta M)\) и \(g^{\mu\nu}\delta g_{\mu\nu} = -g_{\mu\nu}\delta g^{\mu\nu}\):

      \[\begin{equation} \delta\sqrt{-g} = -\frac12\sqrt{-g}\,g_{\mu\nu}\,\delta g^{\mu\nu} . \label{eq:delta-det} \end{equation}\]
      Вычисления

      Шаг 1. Вариация логарифма детерминанта. \(\delta\ln|g| = \mathrm{tr}(g^{-1}\delta g) = g^{\mu\nu}\delta g_{\mu\nu}\), т. е. \(\delta g = g\,g^{\mu\nu}\delta g_{\mu\nu}\).

      Шаг 2. Связь \(\delta g_{\mu\nu}\) и \(\delta g^{\mu\nu}\). Варьируем \(g^{\mu\lambda}g_{\lambda\nu} = \delta^\mu_\nu\): \(\delta g^{\mu\lambda}g_{\lambda\nu} + g^{\mu\lambda}\delta g_{\lambda\nu} = 0\). Свёртка по \(\mu = \nu\): \(g^{\mu\nu}\delta g_{\mu\nu} = -g_{\mu\nu}\delta g^{\mu\nu}\).

      Шаг 3. Корень. \(-g = (\sqrt{-g})^2 > 0\):

      \[ \delta\sqrt{-g} = \frac{-\delta g}{2\sqrt{-g}} = \frac{-g}{2\sqrt{-g}}\,g^{\mu\nu}\delta g_{\mu\nu} = \frac12\sqrt{-g}\,g^{\mu\nu}\delta g_{\mu\nu} = -\frac12\sqrt{-g}\,g_{\mu\nu}\delta g^{\mu\nu} . \]

      Проверка. Масштабирование \(g_{\mu\nu}\to(1+\epsilon)g_{\mu\nu}\) в 4D: \(\sqrt{-g}\to(1+\epsilon)^2\sqrt{-g}\approx(1+2\epsilon)\sqrt{-g}\); формула: \(\tfrac12\sqrt{-g}\,g^{\mu\nu}\epsilon g_{\mu\nu} = 2\epsilon\sqrt{-g}\). Совпадает.

    2. Тождество Палатини. Разность связностей — тензор, и в локально инерциальной системе легко проверить, что

      \[\begin{equation} \delta R_{\mu\nu} = \nabla_\lambda\,\delta\Gamma^\lambda_{\mu\nu} - \nabla_\nu\,\delta\Gamma^\lambda_{\mu\lambda} . \label{eq:palatini} \end{equation}\]

      Поэтому \(\sqrt{-g}\,g^{\mu\nu}\delta R_{\mu\nu} = \sqrt{-g}\,\nabla_\lambda V^\lambda\) — полная производная, не дающая вклада в уравнения (при надлежащем граничном члене Гиббонса — Хокинга).

      Вычисления

      Шаг 1. Риччи через \(\Gamma\). Сворачиваем формулу Римана из conventions по \(R_{\mu\nu} = R^\lambda{}_{\mu\lambda\nu}\):

      \[ R_{\mu\nu} = \pd_\lambda\Gamma^\lambda_{\nu\mu} - \pd_\nu\Gamma^\lambda_{\lambda\mu} + \Gamma^\lambda_{\lambda\sigma}\Gamma^\sigma_{\nu\mu} - \Gamma^\lambda_{\nu\sigma}\Gamma^\sigma_{\lambda\mu} . \]

      Шаг 2. Варьируем в точке \(p\), где \(\Gamma(p) = 0\). Члены \(\Gamma\,\delta\Gamma\) в \(p\) исчезают: \(\delta R_{\mu\nu} = \pd_\lambda\delta\Gamma^\lambda_{\nu\mu} - \pd_\nu\delta\Gamma^\lambda_{\lambda\mu}\).

      Шаг 3. Ковариантизация. \(\delta\Gamma\) — разность двух связностей, т. е. тензор; в \(p\) \(\nabla = \pd\), поэтому \(\delta R_{\mu\nu} = \nabla_\lambda\delta\Gamma^\lambda_{\mu\nu} - \nabla_\nu\delta\Gamma^\lambda_{\mu\lambda}\) (\(\Gamma\) симметричны по нижним индексам). Обе стороны — тензоры, равные в одной системе координат, значит, и во всех.

      Шаг 4. Полная дивергенция. Метрика проходит через \(\nabla\):

      \[ g^{\mu\nu}\delta R_{\mu\nu} = \nabla_\lambda\bigl(g^{\mu\nu}\delta\Gamma^\lambda_{\mu\nu}\bigr) - \nabla_\nu\bigl(g^{\mu\nu}\delta\Gamma^\lambda_{\mu\lambda}\bigr) = \nabla_\lambda V^\lambda,\qquad V^\lambda = g^{\mu\nu}\delta\Gamma^\lambda_{\mu\nu} - g^{\mu\lambda}\delta\Gamma^\sigma_{\mu\sigma} . \]

      С формулой \(\Gamma^\mu_{\mu\lambda} = \pd_\lambda\ln\sqrt{-g}\): \(\sqrt{-g}\,\nabla_\lambda V^\lambda = \pd_\lambda(\sqrt{-g}\,V^\lambda)\) — по теореме Гаусса уходит на границу.

    3. Определение ТЭИ. Для материи

      \[\begin{equation} T_{\mu\nu} = -\frac{2}{\sqrt{-g}}\,\frac{\delta S_M}{\delta g^{\mu\nu}} . \label{eq:tei-def} \end{equation}\]

      Для скалярного поля с \(S_M = -\int\sqrt{-g}\,\bigl(\tfrac12 g^{\mu\nu}\pd_\mu\phi\pd_\nu\phi + V\bigr)\d^4x\) это даёт \(\eqref{eq:tei-fields}\); в плоском пространстве определение совпадает с каноническим (симметризованным) ТЭИ.

      Вычисления

      Шаг 1. Зависимость от \(g^{\mu\nu}\). Лагранжиан \(-\sqrt{-g}\bigl(\tfrac12 g^{\alpha\beta}\pd_\alpha\phi\pd_\beta\phi + V\bigr)\) зависит от \(g^{\mu\nu}\) явно (через \(g^{\alpha\beta}\)) и через \(\sqrt{-g}\); производных метрики нет.

      Шаг 2. Вариация. С \(\eqref{eq:delta-det}\):

      \[ \frac{\delta S_M}{\delta g^{\mu\nu}} = -\sqrt{-g}\,\frac12\pd_\mu\phi\pd_\nu\phi + \frac12\sqrt{-g}\,g_{\mu\nu}\left(\tfrac12 g^{\alpha\beta}\pd_\alpha\phi\pd_\beta\phi + V\right). \]

      Шаг 3. Умножаем на \(-2/\sqrt{-g}\).

      \[ T_{\mu\nu} = \pd_\mu\phi\pd_\nu\phi - g_{\mu\nu}\left(\tfrac12 g^{\alpha\beta}\pd_\alpha\phi\pd_\beta\phi + V\right), \]

      что совпадает с \(\eqref{eq:tei-fields}\) (для скаляра \(\nabla_\mu\phi = \pd_\mu\phi\)).

      Проверка. Однородное поле в покое: \(T_{00} = \tfrac12\dot\phi^2 + V\) — положительная энергия при \(V\ge0\).

    Собирая всё, получаем

    \[ \delta S = \int \sqrt{-g}\,\delta g^{\mu\nu}\left[\frac{1}{16\pi G}\left(R_{\mu\nu} - \frac12 R\, g_{\mu\nu}\right) - \frac12 T_{\mu\nu}\right]\d^4x = 0, \]

    то есть в точности \(\eqref{eq:efe}\). Нормировка \(1/(16\pi G)\) выбрана так, чтобы воспроизвести ньютоновский предел. Бездивергентность \(G_{\mu\nu}\) теперь следует из диффеоморфной инвариантности действия, а \(\eqref{eq:conservation}\) — из уравнений движения материи: тождество Бьянки и закон сохранения — проявления одной и той же симметрии.

    Вычисления

    Шаг 1. Гравитационная часть. Подставляем \(\eqref{eq:delta-det}\) и \(\eqref{eq:palatini}\) в разложение \(\delta(\sqrt{-g}R)\):

    \[ \delta(\sqrt{-g}R) = \sqrt{-g}\,R_{\mu\nu}\delta g^{\mu\nu} - \frac12\sqrt{-g}\,R\,g_{\mu\nu}\delta g^{\mu\nu} + \pd_\lambda(\sqrt{-g}V^\lambda) = \sqrt{-g}\,G_{\mu\nu}\delta g^{\mu\nu} + \text{(граница)} . \]

    Шаг 2. Материя. Обращая \(\eqref{eq:tei-def}\): \(\delta S_M = \int\frac{\delta S_M}{\delta g^{\mu\nu}}\delta g^{\mu\nu}\d^4x = -\frac12\int\sqrt{-g}\,T_{\mu\nu}\delta g^{\mu\nu}\d^4x\).

    Шаг 3. Сумма даёт выражение в тексте; так как \(\delta g^{\mu\nu}\) произвольна, скобка равна нулю: \(\frac{1}{16\pi G}G_{\mu\nu} = \frac12 T_{\mu\nu}\), т. е. \(G_{\mu\nu} = 8\pi G\,T_{\mu\nu}\).

    6.4. Космологическая постоянная¶

    Условиям 1–3 из 6.2 удовлетворяет и сама метрика: \(\nabla^\mu g_{\mu\nu} = 0\). Поэтому самое общее уравнение имеет вид

    \[\begin{equation} G_{\mu\nu} + \Lambda\, g_{\mu\nu} = 8\pi G\,T_{\mu\nu} , \label{eq:efe-lambda} \end{equation}\]

    что соответствует замене \(R \to R - 2\Lambda\) в \(\eqref{eq:hilbert-action}\). Эйнштейн ввёл \(\Lambda > 0\) в 1917 г., чтобы получить статическую Вселенную, а после открытия расширения назвал это «величайшей ошибкой». В 1998 г. по наблюдениям сверхновых Ia было обнаружено ускоренное расширение, и \(\Lambda\) (или нечто её имитирующее) вернулась — см. главу 11.

    Перенеся \(\Lambda g_{\mu\nu}\) направо, видим, что космологическая постоянная эквивалентна идеальной жидкости с \(p = -\rho\):

    \[\begin{equation} T^{\rm (vac)}_{\mu\nu} = -\rho_{\rm vac}\,g_{\mu\nu}, \qquad \rho_{\rm vac} = \frac{\Lambda}{8\pi G}. \label{eq:vacuum-energy} \end{equation}\]
    Вычисления

    Шаг 1. Перенос. \(G_{\mu\nu} = 8\pi G\,T_{\mu\nu} - \Lambda g_{\mu\nu} = 8\pi G\left(T_{\mu\nu} + T^{\rm (vac)}_{\mu\nu}\right)\), где \(T^{\rm (vac)}_{\mu\nu} = -\frac{\Lambda}{8\pi G}g_{\mu\nu}\).

    Шаг 2. Сравнение с жидкостью. \(\eqref{eq:perfect-fluid}\) при \(p = -\rho\): \((\rho - \rho)U_\mu U_\nu - \rho\,g_{\mu\nu} = -\rho\,g_{\mu\nu}\), откуда \(\rho_{\rm vac} = \Lambda/(8\pi G)\), \(p_{\rm vac} = -\rho_{\rm vac}\).

    Шаг 3. Действие. Добавка \(-2\Lambda\sqrt{-g}\) варьируется по \(\eqref{eq:delta-det}\): \(\delta(-2\Lambda\sqrt{-g}) = \Lambda\sqrt{-g}\,g_{\mu\nu}\delta g^{\mu\nu}\), и в скобке \(\delta S\) появляется \(\frac{1}{16\pi G}(G_{\mu\nu} + \Lambda g_{\mu\nu})\) — это \(\eqref{eq:efe-lambda}\).

    Лоренц-инвариантность требует, чтобы ТЭИ вакуума был пропорционален \(\eta_{\mu\nu}\), так что любая энергия нулевых колебаний квантовых полей гравитирует как \(\Lambda\). Наблюдаемое значение \(\rho_{\rm vac} \approx 6\cdot10^{-27}\) кг/м³ \(\sim (2{,}2~\text{мэВ})^4\) на \(\sim120\) порядков меньше наивной оценки \(M_{\rm Pl}^4\) — проблема космологической постоянной.

    6.5. Ньютоновский предел¶

    Найдём \(\kappa\) в \(G_{\mu\nu} = \kappa T_{\mu\nu}\). Используем форму с обращённым следом: \(R_{\mu\nu} = \kappa(T_{\mu\nu} - \tfrac12 T g_{\mu\nu})\). Рассмотрим статическую пыль \(T_{\mu\nu} = \rho U_\mu U_\nu\) в слабом поле; в главном порядке \(U^\mu = (1, 0, 0, 0)\), \(U_0 = -1\), \(T_{00} = \rho\), \(T = g^{00}T_{00} = -\rho\). Тогда

    \[ R_{00} = \kappa\left(\rho - \frac12(-\rho)(-1)\right) = \frac{\kappa}{2}\,\rho . \]

    Левую часть вычислим, используя \(R_{00} = R^\lambda{}_{0\lambda0}\). Для статического поля временные производные равны нулю, а произведения \(\Gamma\Gamma\) — второго порядка по \(h\), так что

    \[\begin{equation} R_{00} \approx \pd_i\Gamma^i_{00} = \pd_i\left(-\frac12\pd_i h_{00}\right) = \nabla^2\Phi , \label{eq:r00} \end{equation}\]

    где использованы \(\Gamma^i_{00} = -\frac12\pd_i h_{00}\) и \(h_{00} = -2\Phi\) из главы 5. Сравнивая, \(\nabla^2\Phi = \frac{\kappa}{2}\rho\), и уравнение Пуассона требует

    \[\begin{equation} \kappa = 8\pi G . \label{eq:kappa} \end{equation}\]
    Вычисления

    Шаг 1. Правая часть. \(g_{00} \approx -1\), \(g^{00}\approx-1\); у пыли в покое отлична от нуля только \(T_{00} = \rho\): \(T = g^{00}T_{00} = -\rho\), и

    \[ T_{00} - \tfrac12 T g_{00} = \rho - \tfrac12(-\rho)(-1) = \tfrac12\rho . \]

    Шаг 2. Левая часть. По формуле Римана с \(\sigma = \nu = 0\): \(R_{00} = R^\lambda{}_{0\lambda0} = \pd_\lambda\Gamma^\lambda_{00} - \pd_0\Gamma^\lambda_{\lambda0} + O(h^2)\). Второй член и \(\lambda = 0\) в первом содержат \(\pd_0\) — нуль. Остаётся \(\pd_i\Gamma^i_{00}\).

    Шаг 3. Подстановка. \(\Gamma^i_{00} = -\tfrac12\pd_i h_{00} = -\tfrac12\pd_i(-2\Phi) = \pd_i\Phi\), откуда \(R_{00} = \pd_i\pd_i\Phi = \nabla^2\Phi\).

    Шаг 4. Сравнение. \(\nabla^2\Phi = \tfrac\kappa2\rho\) и \(\nabla^2\Phi = 4\pi G\rho\) ⇒ \(\kappa = 8\pi G\).

    Проверка (размерность). С \(c\): \(\kappa = 8\pi G/c^4\); \([G_{\mu\nu}] = \text{м}^{-2}\), \([T_{\mu\nu}] = \text{Дж/м}^3\), \([G/c^4] = \text{м}/\text{Дж}\) — сходится.

    Активная гравитационная масса и давление

    Для статической идеальной жидкости с давлением аналогичный расчёт даёт \(R_{00} = 4\pi G(\rho + 3p)\): в ОТО гравитирует не только энергия, но и давление. Для излучения \(\rho + 3p = 2\rho\), для вакуумной энергии \(\rho + 3p = -2\rho < 0\) — космологическая постоянная отталкивает. Это и есть причина ускоренного расширения.

    Вычисления

    Шаг 1. В покое \(T_{00} = \rho\), \(T = 3p - \rho\), \(g_{00}\approx -1\):

    \[ T_{00} - \tfrac12 T g_{00} = \rho + \tfrac12(3p - \rho) = \tfrac12(\rho + 3p) . \]

    Шаг 2. По \(\eqref{eq:efe-trace-reversed}\) \(R_{00} = 8\pi G\cdot\tfrac12(\rho+3p) = 4\pi G(\rho+3p)\), т. е. \(\nabla^2\Phi = 4\pi G(\rho + 3p)\).

    Шаг 3. Излучение \(p = \rho/3\): \(\rho + \rho = 2\rho\). Вакуум \(p = -\rho\): \(\rho - 3\rho = -2\rho\).

    Полный слабополевой анализ (с \(g_{ij}\)) даёт метрику вне медленно движущихся источников

    \[\begin{equation} \d s^2 = -(1 + 2\Phi)\,\d t^2 + (1 - 2\Phi)\,\d\vb x^2 , \label{eq:weak-field} \end{equation}\]

    причём пространственная часть, несущественная для медленных тел, удваивает отклонение света (глава 7).

    6.6. Энергетические условия¶

    Уравнения Эйнштейна без ограничений на \(T_{\mu\nu}\) пусты: любую метрику можно «решить», объявив \(T_{\mu\nu} \equiv G_{\mu\nu}/(8\pi G)\). Нужны физически мотивированные условия, не привязанные к конкретной материи.

    Энергетические условия

    Пусть \(t^\mu\) — произвольный времениподобный, \(\ell^\mu\) — произвольный изотропный вектор.

    • Слабое (WEC): \(T_{\mu\nu}t^\mu t^\nu \ge 0\) — любой наблюдатель видит неотрицательную плотность энергии.
    • Изотропное (NEC): \(T_{\mu\nu}\ell^\mu\ell^\nu \ge 0\).
    • Доминантное (DEC): WEC и вектор \(-T^\mu{}_\nu t^\nu\) непространственноподобен — энергия не течёт быстрее света.
    • Сильное (SEC): \(\left(T_{\mu\nu} - \frac12 T g_{\mu\nu}\right)t^\mu t^\nu \ge 0\).

    Для идеальной жидкости \(\eqref{eq:perfect-fluid}\) условия принимают вид

    Условие Ограничение на \(\rho,\ p\)
    NEC \(\rho + p \ge 0\)
    WEC \(\rho \ge 0,\ \rho + p \ge 0\)
    DEC \(\rho \ge \lvert p\rvert\)
    SEC \(\rho + p \ge 0,\ \rho + 3p \ge 0\)

    По \(\eqref{eq:efe-trace-reversed}\) SEC эквивалентно \(R_{\mu\nu}t^\mu t^\nu \ge 0\), т.е. притяжению близких времениподобных геодезических (уравнение Райчаудхури). Именно SEC используется в теоремах Хокинга — Пенроуза о сингулярностях, а NEC — в теореме о неубывании площади горизонта (глава 8).

    Вычисления

    Шаг 1. Параметризация. В системе покоя жидкости любой единичный времениподобный вектор — \(t^\mu = \gamma(1, v\vb n)\), \(\gamma = (1-v^2)^{-1/2}\ge1\); тогда \(U\cdot t = -\gamma\), \(t\cdot t = -1\). Изотропный: \(\ell^\mu = (1,\vb n)\), \(U\cdot\ell = -1\), \(\ell\cdot\ell = 0\).

    Шаг 2. WEC и NEC.

    \[ T_{\mu\nu}t^\mu t^\nu = (\rho+p)\gamma^2 - p, \qquad T_{\mu\nu}\ell^\mu\ell^\nu = \rho + p . \]

    Неотрицательность при всех \(\gamma\): \(\gamma = 1\) даёт \(\rho\ge0\), \(\gamma\to\infty\) — \(\rho+p\ge0\) (при этих двух условиях выражение возрастает по \(\gamma^2\) и всегда \(\ge\rho\)).

    Шаг 3. SEC. \(T = 3p - \rho\), \(g_{\mu\nu}t^\mu t^\nu = -1\):

    \[ \left(T_{\mu\nu} - \tfrac12 T g_{\mu\nu}\right)t^\mu t^\nu = (\rho+p)\gamma^2 - p + \tfrac12(3p-\rho) = (\rho+p)\gamma^2 + \tfrac12(p - \rho) . \]

    \(\gamma = 1\): \(\tfrac12(\rho + 3p)\ge0\); \(\gamma\to\infty\): \(\rho + p\ge0\).

    Шаг 4. DEC. \(T^\mu{}_\nu = \mathrm{diag}(-\rho, p, p, p)\), \(-T^\mu{}_\nu t^\nu = \gamma(\rho,\,-p\,v\vb n)\). Непространственноподобие: \(-\rho^2 + p^2v^2 \le 0\) для всех \(v<1\) ⇔ \(|p|\le|\rho|\); вместе с \(\rho\ge0\) (WEC): \(\rho\ge|p|\).

    Шаг 5. SEC и Риччи. По \(\eqref{eq:efe-trace-reversed}\) \(R_{\mu\nu}t^\mu t^\nu = 8\pi G(T_{\mu\nu} - \tfrac12 T g_{\mu\nu})t^\mu t^\nu\), так что знаки совпадают.

    Обратите внимание: SEC не следует из WEC, и наоборот. Космологическая постоянная (\(w = -1\)) удовлетворяет NEC, WEC и DEC, но нарушает SEC; так же ведёт себя инфлатон (глава 15). Нарушение SEC — необходимое условие ускоренного расширения. Квантовые поля могут нарушать и NEC локально (эффект Казимира), но, по-видимому, не в среднем вдоль геодезических.

    Интерактив: энергетические условия¶

    Выберите плотность \(\rho\) и давление \(p\) идеальной жидкости. Цветом показаны области, где выполнено каждое условие (наложение цветов — несколько условий сразу). Отмечены точки пыли, излучения, вакуумной энергии и граничного \(w = -1/3\) (предел SEC при \(\rho > 0\)).

    6.7. Символьная проверка¶

    Проверим с помощью sympy, что метрика Шварцшильда (глава 7) — решение вакуумных уравнений, и выпишем компоненту \(G_{tt}\) общей статической сферически-симметричной метрики. Код реализует формулы из conventions буквально.

    import sympy as sp

t, r, th, ph = sp.symbols('t r theta phi')
M = sp.symbols('M', positive=True)
x = [t, r, th, ph]

def einstein(g):
    gi = g.inv()
    n = 4
    Gam = [[[sp.simplify(sum(gi[l, s] * (sp.diff(g[n_, s], x[m]) + sp.diff(g[m, s], x[n_])
             - sp.diff(g[m, n_], x[s])) for s in range(n)) / 2)
             for n_ in range(n)] for m in range(n)] for l in range(n)]
    # R_{μν} = ∂_λ Γ^λ_{μν} − ∂_ν Γ^λ_{μλ} + Γ^λ_{λσ}Γ^σ_{μν} − Γ^λ_{νσ}Γ^σ_{μλ}
    Ric = sp.zeros(n)
    for m in range(n):
        for n_ in range(n):
            Ric[m, n_] = sp.simplify(sum(
                sp.diff(Gam[l][m][n_], x[l]) - sp.diff(Gam[l][m][l], x[n_])
                + sum(Gam[l][l][s] * Gam[s][m][n_] - Gam[l][n_][s] * Gam[s][m][l]
                      for s in range(n)) for l in range(n)))
    Rs = sp.simplify(sum(gi[a, b] * Ric[a, b] for a in range(n) for b in range(n)))
    return sp.simplify(Ric - Rs * g / 2), Rs

# 1) Шварцшильд (G = 1) — вакуумное решение
f = 1 - 2 * M / r
g = sp.diag(-f, 1 / f, r**2, r**2 * sp.sin(th)**2)
Gt, Rs = einstein(g)
print(Gt == sp.zeros(4), Rs)          # True 0

# 2) Статическое сферически-симметричное поле общего вида: G_tt
A, B = sp.Function('A')(r), sp.Function('B')(r)
g2 = sp.diag(-sp.exp(2 * A), sp.exp(2 * B), r**2, r**2 * sp.sin(th)**2)
Gt2, _ = einstein(g2)
print(sp.simplify(Gt2[0, 0] * sp.exp(-2 * A)))
# (2*r*Derivative(B(r), r) + exp(2*B(r)) - 1)*exp(-2*B(r))/r**2

    Второй результат можно переписать как \(e^{-2A}G_{tt} = \frac{1}{r^2}\frac{\d}{\d r}\bigl[r(1 - e^{-2B})\bigr]\). Положив \(e^{-2B} = 1 - 2Gm(r)/r\), из \(G_{tt} = 8\pi G\,\rho\,e^{2A}\) получаем \(\d m/\d r = 4\pi r^2\rho\) — «массовую функцию» звезды, первое из уравнений Толмена — Оппенгеймера — Волкова.

    Задачи¶

    6.1. След уравнений Эйнштейна

    Найдите скаляр Риччи для пространства, заполненного (а) излучением, (б) пылью плотности \(\rho\), (в) только космологической постоянной (\(T_{\mu\nu} = 0\)). Чему равен \(R\) в \(n\) измерениях для вакуума с \(\Lambda\)?

    Решение

    Из \(\eqref{eq:efe-lambda}\): \(-R + 4\Lambda = 8\pi G T\). (а) \(T = -\rho + 3p = 0\), \(R = 0\). (б) \(T = -\rho\), \(R = 8\pi G\rho\). (в) \(R = 4\Lambda\). В \(n\) измерениях \(g^{\mu\nu}g_{\mu\nu} = n\): \((1 - n/2)R + n\Lambda = 0\), \(R = \frac{2n}{n-2}\Lambda\).

    6.2. Бесследовость поля Максвелла

    Покажите, что \(T^{\rm (EM)}_{\mu\nu}\) из \(\eqref{eq:tei-fields}\) бесследов в четырёх измерениях, и найдите \(T_{00}\) в локально инерциальной системе.

    Решение

    \(g^{\mu\nu}T_{\mu\nu} = F_{\mu\lambda}F^{\mu\lambda} - \frac{4}{4}F^2 = 0\). С \(F_{0i} = -E_i\), \(F_{ij} = \epsilon_{ijk}B_k\): \(F_{\lambda\sigma}F^{\lambda\sigma} = 2(B^2 - E^2)\), \(F_{0\lambda}F_0{}^\lambda = E^2\), откуда \(T_{00} = E^2 + \tfrac12(B^2 - E^2) = \tfrac12(E^2 + B^2)\) (единицы Хевисайда — Лоренца).

    6.3. Пыль движется по геодезическим

    Из \(\nabla_\mu(\rho U^\mu U^\nu) = 0\) выведите (а) уравнение непрерывности \(\nabla_\mu(\rho U^\mu) = 0\) и (б) \(U^\mu\nabla_\mu U^\nu = 0\).

    Решение

    \(\nabla_\mu(\rho U^\mu U^\nu) = U^\nu\nabla_\mu(\rho U^\mu) + \rho U^\mu\nabla_\mu U^\nu\). Свернём с \(U_\nu\): \(U_\nu U^\nu = -1\), а \(U_\nu U^\mu\nabla_\mu U^\nu = \tfrac12 U^\mu\nabla_\mu(U_\nu U^\nu) = 0\). Отсюда (а); подставляя (а) обратно, получаем (б) при \(\rho \ne 0\).

    6.4. Энергия вакуума

    Наблюдаемое значение \(\Omega_\Lambda \approx 0{,}69\) при \(H_0 = 67{,}7\) км/с/Мпк. Найдите \(\rho_{\rm vac}\) в кг/м³, \(\Lambda\) в м\(^{-2}\) и энергетический масштаб \(\rho_{\rm vac}^{1/4}\) в эВ.

    Решение

    \(H_0 = 2{,}19\cdot10^{-18}\) с\(^{-1}\), \(\rho_{\rm cr} = 3H_0^2/(8\pi G) = 8{,}6\cdot10^{-27}\) кг/м³, \(\rho_{\rm vac} = 5{,}9\cdot10^{-27}\) кг/м³. \(\Lambda = 8\pi G\rho_{\rm vac}/c^2 = 3\Omega_\Lambda H_0^2/c^2 = 1{,}1\cdot10^{-52}\) м\(^{-2}\). Плотность энергии \(\rho c^2 = 5{,}3\cdot10^{-10}\) Дж/м³ \(= 3{,}3\cdot10^{9}\) эВ/м³; умножая на \((\hbar c)^3 = (1{,}97\cdot10^{-7}\text{ эВ·м})^3\), получаем \(2{,}5\cdot10^{-11}\) эВ\(^4\), т.е. \(\rho_{\rm vac}^{1/4} \approx 2{,}2\) мэВ.

    6.5. Скалярное поле и SEC

    Для однородного скалярного поля \(\phi(t)\) в локально инерциальной системе найдите \(\rho\) и \(p\) из \(\eqref{eq:tei-fields}\). При каком условии нарушается SEC?

    Решение

    \(\nabla_\mu\phi = (\dot\phi, 0,0,0)\), \(g^{\lambda\sigma}\pd_\lambda\phi\pd_\sigma\phi = -\dot\phi^2\). \(T_{00} = \dot\phi^2 - (-1)(-\tfrac12\dot\phi^2 + V) = \tfrac12\dot\phi^2 + V = \rho\), \(T_{ii} = -(-\tfrac12\dot\phi^2 + V) = \tfrac12\dot\phi^2 - V = p\). \(\rho + 3p = 2(\dot\phi^2 - V) < 0\) при \(V > \dot\phi^2\) — режим медленного скатывания в инфляции.

    6.6. Тождество Бьянки

    Выведите \(\eqref{eq:bianchi}\) из тождества Бьянки \(\nabla_{[\lambda}R_{\rho\sigma]\mu\nu} = 0\) и проверьте \(\nabla^\mu G_{\mu\nu} = 0\).

    Решение

    Тождество: \(\nabla_\lambda R_{\rho\sigma\mu\nu} + \nabla_\rho R_{\sigma\lambda\mu\nu} + \nabla_\sigma R_{\lambda\rho\mu\nu} = 0\). Свернём по \(g^{\nu\sigma}\): \(\nabla_\lambda R_{\rho\mu} - \nabla_\rho R_{\lambda\mu} + \nabla^\nu R_{\lambda\rho\mu\nu} = 0\). Свернём ещё по \(g^{\mu\lambda}\): \(\nabla^\mu R_{\rho\mu} - \nabla_\rho R + \nabla^\nu R_{\rho\nu} = 0\), т.е. \(2\nabla^\mu R_{\mu\rho} = \nabla_\rho R\). Тогда \(\nabla^\mu G_{\mu\nu} = \tfrac12\nabla_\nu R - \tfrac12\nabla_\nu R = 0\).
