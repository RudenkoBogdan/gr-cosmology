# Обозначения и соглашения

## Единицы

Всюду, если не оговорено иное, **\(c = 1\)**. Гравитационная постоянная \(G\) и
постоянная Планка \(\hbar\) выписываются явно. Чтобы восстановить \(c\), достаточно
проверить размерности: время \(t \to ct\), скорость \(v \to v/c\), энергия \(E \to E/c^2\)
в роли массы.

## Метрика и индексы

- Сигнатура **\((-,+,+,+)\)**: \(\eta_{\mu\nu} = \mathrm{diag}(-1, 1, 1, 1)\).
- Греческие индексы \(\mu, \nu, \ldots = 0,1,2,3\); латинские \(i, j, \ldots = 1,2,3\).
- Правило Эйнштейна: по повторяющимся верхнему и нижнему индексам подразумевается суммирование.
- Интервал: \(\d s^2 = g_{\mu\nu}\,\d x^\mu \d x^\nu\); времениподобные интервалы имеют \(\d s^2 < 0\),
  собственное время \(\d\tau^2 = -\d s^2\).

## Кривизна (соглашения MTW / Кэрролла)

\[
\Gamma^\lambda_{\mu\nu} = \tfrac12 g^{\lambda\sigma}\left(\pd_\mu g_{\nu\sigma} + \pd_\nu g_{\mu\sigma} - \pd_\sigma g_{\mu\nu}\right),
\]
\[
R^\rho{}_{\sigma\mu\nu} = \pd_\mu \Gamma^\rho_{\nu\sigma} - \pd_\nu \Gamma^\rho_{\mu\sigma}
 + \Gamma^\rho_{\mu\lambda}\Gamma^\lambda_{\nu\sigma} - \Gamma^\rho_{\nu\lambda}\Gamma^\lambda_{\mu\sigma},
\qquad R_{\mu\nu} = R^\lambda{}_{\mu\lambda\nu}.
\]

Уравнения Эйнштейна:
\[
G_{\mu\nu} + \Lambda g_{\mu\nu} = 8\pi G\, T_{\mu\nu}.
\]

## Космология

- Масштабный фактор \(a(t)\), нормировка \(a(t_0) = 1\); индекс \(0\) — сегодняшнее значение.
- Параметр Хаббла \(H = \dot a / a\), \(H_0 = 100\,h\) км/с/Мпк.
- Параметры плотности \(\Omega_i = \rho_i / \rho_{\rm cr}\), \(\rho_{\rm cr} = 3H^2/(8\pi G)\).
