# Глоссарий

Интервал
:   Инвариант \(\d s^2 = g_{\mu\nu}\d x^\mu \d x^\nu\). См. [гл. 1](../part1-math/01-special-relativity.md).

Собственное время
:   Время, измеряемое часами вдоль мировой линии: \(\d\tau^2 = -\d s^2\).

4-скорость
:   \(U^\mu = \d x^\mu/\d\tau\), нормирована условием \(U_\mu U^\mu = -1\).

Быстрота
:   Параметр буста \(\phi\), \(v = \tanh\phi\); аддитивна для бустов вдоль одной оси.

Световой конус
:   Множество изотропных направлений \(\d s^2 = 0\) из события; задаёт причинную структуру.

Тензор энергии-импульса
:   Симметричный тензор \(T^{\mu\nu}\) — плотность и поток 4-импульса.
