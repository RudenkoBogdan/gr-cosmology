# Глоссарий

Интервал
:   Инвариант \(\d s^2 = g_{\mu\nu}\d x^\mu \d x^\nu\). См. [гл. 1](../part1-math/01-special-relativity.md).

Собственное время
:   Время, измеряемое часами вдоль мировой линии: \(\d\tau^2 = -\d s^2\).

4-скорость
:   \(U^\mu = \d x^\mu/\d\tau\), нормирована условием \(U_\mu U^\mu = -1\).

Быстрота
:   Параметр буста \(\phi\), \(v = \tanh\phi\); аддитивна для бустов вдоль одной оси.

Световой конус
:   Множество изотропных направлений \(\d s^2 = 0\) из события; задаёт причинную структуру.

Тензор энергии-импульса
:   Симметричный тензор \(T^{\mu\nu}\) — плотность и поток 4-импульса.

Метрический тензор
:   Симметричный невырожденный тензор \(g_{\mu\nu}\), задающий скалярное произведение, длины и интервалы. См. [гл. 2](../part1-math/02-manifolds-tensors.md).

Многообразие
:   Пространство, локально устроенное как \(\mathbb R^n\), с гладкими картами. См. [гл. 2](../part1-math/02-manifolds-tensors.md).

Символы Кристоффеля
:   Коэффициенты связности Леви-Чивиты \(\Gamma^\lambda_{\mu\nu} = \tfrac12 g^{\lambda\sigma}(\pd_\mu g_{\sigma\nu} + \pd_\nu g_{\sigma\mu} - \pd_\sigma g_{\mu\nu})\). См. [гл. 3](../part1-math/03-connection.md).

Ковариантная производная
:   Производная \(\nabla_\mu\), переводящая тензоры в тензоры. См. [гл. 3](../part1-math/03-connection.md).

Геодезическая
:   Кривая, касательный вектор которой параллельно переносится вдоль неё; траектория свободной частицы. См. [гл. 3](../part1-math/03-connection.md), [гл. 5](../part2-gr/05-equivalence.md).

Вектор Киллинга
:   Векторное поле \(\xi^\mu\), вдоль которого метрика не меняется: \(\nabla_{(\mu}\xi_{\nu)} = 0\); порождает сохраняющиеся величины. См. [гл. 3](../part1-math/03-connection.md).

Тензор Римана
:   Тензор кривизны \(R^\rho{}_{\sigma\mu\nu}\), измеряющий некоммутативность ковариантных производных. См. [гл. 4](../part1-math/04-curvature.md).

Тензор Эйнштейна
:   \(G_{\mu\nu} = R_{\mu\nu} - \tfrac12 R g_{\mu\nu}\); бездивергентен в силу тождеств Бьянки. См. [гл. 4](../part1-math/04-curvature.md).

Отклонение геодезических
:   Относительное ускорение соседних геодезических, определяемое тензором Римана (приливные силы). См. [гл. 4](../part1-math/04-curvature.md).

Принцип эквивалентности
:   Локально гравитационное поле неотличимо от ускоренной системы отсчёта; в локально инерциальной системе справедлива СТО. См. [гл. 5](../part2-gr/05-equivalence.md).

Гравитационное красное смещение
:   Изменение частоты света при движении в гравитационном поле; в слабом поле \(\Delta\nu/\nu \approx -\Delta\Phi/c^2\). См. [гл. 5](../part2-gr/05-equivalence.md).

Уравнения Эйнштейна
:   \(G_{\mu\nu} + \Lambda g_{\mu\nu} = 8\pi G\,T_{\mu\nu}\) (при \(c = 1\)). См. [гл. 6](../part2-gr/06-einstein-equations.md).

Действие Гильберта
:   \(S = \frac{1}{16\pi G}\int R\sqrt{-g}\,\d^4x\), варьирование которого даёт уравнения Эйнштейна. См. [гл. 6](../part2-gr/06-einstein-equations.md).

Энергетические условия
:   Ограничения на \(T_{\mu\nu}\) (слабое, нулевое, сильное, доминантное), используемые в теоремах ОТО. См. [гл. 6](../part2-gr/06-einstein-equations.md).

Космологическая постоянная
:   Член \(\Lambda g_{\mu\nu}\) в уравнениях Эйнштейна; эквивалентна энергии вакуума с \(w = -1\). См. [гл. 6](../part2-gr/06-einstein-equations.md).

Метрика Шварцшильда
:   Единственное сферически-симметричное вакуумное решение (теорема Биркгофа). См. [гл. 7](../part2-gr/07-schwarzschild.md).

Радиус Шварцшильда
:   \(r_s = 2GM\) (при \(c = 1\)); положение горизонта невращающейся чёрной дыры. См. [гл. 7](../part2-gr/07-schwarzschild.md).

Прецессия перигелия
:   Поворот орбиты за оборот \(\Delta\varphi = 6\pi GM/[a(1-e^2)]\); для Меркурия 43″ в столетие. См. [гл. 7](../part2-gr/07-schwarzschild.md).

Задержка Шапиро
:   Дополнительное время распространения сигнала вблизи массивного тела. См. [гл. 7](../part2-gr/07-schwarzschild.md).

Горизонт событий
:   Граница области, из которой сигналы не достигают бесконечности. См. [гл. 8](../part2-gr/08-black-holes.md).

Координаты Крускала–Секереша
:   Координаты, покрывающие полное аналитическое продолжение решения Шварцшильда. См. [гл. 8](../part2-gr/08-black-holes.md).

Диаграмма Пенроуза
:   Конформная компактификация пространства-времени, изображающая бесконечность на конечном расстоянии. См. [гл. 8](../part2-gr/08-black-holes.md).

Решение Керра
:   Метрика вращающейся чёрной дыры с массой \(M\) и моментом \(J\). См. [гл. 8](../part2-gr/08-black-holes.md).

Излучение Хокинга
:   Тепловое излучение чёрной дыры с температурой \(T_H = \hbar c^3/(8\pi G M k_B)\). См. [гл. 8](../part2-gr/08-black-holes.md).

Калибровка TT
:   Поперечная бесследовая калибровка для гравитационных волн, оставляющая две поляризации \(h_+\), \(h_\times\). См. [гл. 9](../part2-gr/09-gravitational-waves.md).

Квадрупольная формула
:   Мощность гравитационного излучения \(P = \frac{G}{5}\langle\dddot{Q}_{ij}\dddot{Q}^{ij}\rangle\) (\(c = 1\)). См. [гл. 9](../part2-gr/09-gravitational-waves.md).

Чирп-масса
:   Комбинация масс двойной системы \(\mathcal M = (m_1m_2)^{3/5}/(m_1+m_2)^{1/5}\), определяющая эволюцию частоты сигнала. См. [гл. 9](../part2-gr/09-gravitational-waves.md).

Космологический принцип
:   Вселенная на больших масштабах однородна и изотропна. См. [гл. 10](../part3-cosmology/10-frw.md).

Метрика FLRW
:   \(\d s^2 = -\d t^2 + a^2(t)\left[\d\chi^2 + S_k^2(\chi)\,\d\Omega^2\right]\) — метрика однородной изотропной Вселенной. См. [гл. 10](../part3-cosmology/10-frw.md).

Масштабный фактор
:   Функция \(a(t)\), описывающая расширение; \(1 + z = a_0/a\). См. [гл. 10](../part3-cosmology/10-frw.md).

Постоянная Хаббла
:   \(H_0 = \dot a/a\) сегодня; \(H_0 = 100h\) км/с/Мпк. См. [гл. 10](../part3-cosmology/10-frw.md).

Уравнения Фридмана
:   \(H^2 = \frac{8\pi G}{3}\rho - \frac{k}{a^2}\) и \(\ddot a/a = -\frac{4\pi G}{3}(\rho + 3p)\). См. [гл. 11](../part3-cosmology/11-friedmann.md).

Параметр плотности
:   \(\Omega_i = \rho_i/\rho_{\rm cr}\), \(\rho_{\rm cr} = 3H^2/(8\pi G)\). См. [гл. 11](../part3-cosmology/11-friedmann.md).

Уравнение состояния
:   Связь \(p = w\rho\); \(w = 0\) — вещество, \(1/3\) — излучение, \(-1\) — вакуум. См. [гл. 11](../part3-cosmology/11-friedmann.md).

Модель ΛCDM
:   Стандартная плоская модель с космологической постоянной и холодной тёмной материей. См. [гл. 11](../part3-cosmology/11-friedmann.md).

Фотометрическое расстояние
:   \(d_L = (1+z)D_M\), определяемое по потоку от источника известной светимости. См. [гл. 12](../part3-cosmology/12-distances.md).

Угловое расстояние
:   \(d_A = D_M/(1+z)\), определяемое по угловому размеру объекта известного размера. См. [гл. 12](../part3-cosmology/12-distances.md).

Горизонт частиц
:   Сопутствующее расстояние, пройденное светом с начала расширения: \(\chi_{\rm p} = \int \d t/a\). См. [гл. 12](../part3-cosmology/12-distances.md), [гл. 15](../part4-perturbations/15-inflation.md).

Число релятивистских степеней свободы
:   \(g_*(T)\), определяющее плотность энергии излучения \(\rho = \frac{\pi^2}{30}g_*T^4\). См. [гл. 13](../part3-cosmology/13-thermal-history.md).

Закалка (freeze-out)
:   Выход реакции из равновесия, когда её темп падает ниже \(H\). См. [гл. 13](../part3-cosmology/13-thermal-history.md).

Уравнение Саха
:   Равновесная доля ионизации водорода как функция температуры. См. [гл. 13](../part3-cosmology/13-thermal-history.md).

Рекомбинация
:   Образование нейтральных атомов при \(z \approx 1100\), после которого Вселенная становится прозрачной. См. [гл. 13](../part3-cosmology/13-thermal-history.md).

Первичный нуклеосинтез
:   Синтез D, ³He, ⁴He, ⁷Li в первые минуты; ограничивает \(\eta = n_b/n_\gamma\) и \(N_{\rm eff}\). См. [гл. 14](../part3-cosmology/14-bbn.md).

Дейтериевое бутылочное горлышко
:   Задержка нуклеосинтеза до \(T \approx 0.07\) МэВ из-за фоторазрушения дейтерия. См. [гл. 14](../part3-cosmology/14-bbn.md).

Массовая доля гелия
:   \(Y_p \approx 2(n/p)/(1 + n/p) \approx 0.25\). См. [гл. 14](../part3-cosmology/14-bbn.md).

Инфляция
:   Эпоха ускоренного расширения (\(\ddot a > 0\)), во время которой сопутствующий хаббловский радиус \((aH)^{-1}\) убывает. См. [гл. 15](../part4-perturbations/15-inflation.md).

Инфлатон
:   Скалярное поле \(\phi\), энергия потенциала которого управляет инфляцией. См. [гл. 15](../part4-perturbations/15-inflation.md).

Параметры медленного скатывания
:   \(\epsilon_V = \frac{M_{\rm Pl}^2}{2}(V'/V)^2\), \(\eta_V = M_{\rm Pl}^2V''/V\); дают \(n_s - 1 = 2\eta_V - 6\epsilon_V\), \(r = 16\epsilon_V\). См. [гл. 15](../part4-perturbations/15-inflation.md).

Е-фолд
:   Единица длительности инфляции: \(N = \ln(a_{\rm end}/a)\); для решения проблемы горизонта нужно \(N \gtrsim 50\text{–}60\). См. [гл. 15](../part4-perturbations/15-inflation.md).

Спектральный индекс
:   \(n_s\), наклон первичного спектра \(\Delta^2_{\mathcal R} \propto k^{n_s - 1}\); Planck: \(n_s = 0.965\). См. [гл. 15](../part4-perturbations/15-inflation.md).

Отношение тензор/скаляр
:   \(r = A_t/A_s\); сейчас \(r < 0.036\). См. [гл. 15](../part4-perturbations/15-inflation.md).

Разогрев
:   Распад инфлатона на частицы Стандартной модели после инфляции. См. [гл. 15](../part4-perturbations/15-inflation.md).

Калибровочная свобода
:   Неоднозначность разбиения метрики на фон и возмущение при малых заменах координат. См. [гл. 16](../part4-perturbations/16-perturbations.md).

Потенциалы Бардина
:   Калибровочно-инвариантные скалярные возмущения метрики \(\Psi\), \(\Phi\). См. [гл. 16](../part4-perturbations/16-perturbations.md).

Ньютоновская калибровка
:   Калибровка \(B = E = 0\): \(\d s^2 = a^2[-(1+2\Psi)\d\tau^2 + (1-2\Phi)\d\vb x^2]\). См. [гл. 16](../part4-perturbations/16-perturbations.md).

Кривизна сопутствующих гиперповерхностей
:   Калибровочно-инвариантная величина \(\mathcal R\), сохраняющаяся вне горизонта для адиабатических возмущений. См. [гл. 16](../part4-perturbations/16-perturbations.md).

Эффект Мезароша
:   Логарифмический (а не степенной) рост возмущений тёмной материи под горизонтом в радиационную эпоху. См. [гл. 16](../part4-perturbations/16-perturbations.md).

Фактор роста
:   \(D(a)\) — растущее решение линейного уравнения для контраста плотности; \(f = \d\ln D/\d\ln a \approx \Omega_m^{0.55}\). См. [гл. 16](../part4-perturbations/16-perturbations.md).

Угловой спектр мощности
:   \(C_\ell\), дисперсия коэффициентов \(a_{\ell m}\) разложения анизотропии CMB. См. [гл. 17](../part4-perturbations/17-cmb.md).

Космическая дисперсия
:   Неустранимая неопределённость \(\Delta C_\ell/C_\ell = \sqrt{2/(2\ell+1)}\) из-за наличия одного неба. См. [гл. 17](../part4-perturbations/17-cmb.md).

Эффект Сакса–Вольфа
:   Анизотропия CMB на больших масштабах \(\Delta T/T = \Psi/3 = \mathcal R/5\). См. [гл. 17](../part4-perturbations/17-cmb.md).

Звуковой горизонт
:   Сопутствующее расстояние, пройденное звуком в барион-фотонной плазме: \(r_s = \int c_s\,\d\tau\). См. [гл. 17](../part4-perturbations/17-cmb.md).

Акустические пики
:   Максимумы \(C_\ell\) при \(\ell_n \approx \ell_A(n - \varphi)\), \(\ell_A = \pi D_M/r_{s*}\). См. [гл. 17](../part4-perturbations/17-cmb.md).

Затухание Силка
:   Экспоненциальное подавление анизотропии на малых масштабах из-за диффузии фотонов. См. [гл. 17](../part4-perturbations/17-cmb.md).

E- и B-моды
:   Градиентная и вихревая части поляризации CMB; первичные B-моды — сигнатура гравитационных волн от инфляции. См. [гл. 17](../part4-perturbations/17-cmb.md).

Спектр мощности материи
:   \(P(k)\): \(\langle\delta_{\vb k}\delta^*_{\vb k'}\rangle = (2\pi)^3\delta_D(\vb k - \vb k')P(k)\). См. [гл. 18](../part4-perturbations/18-lss.md).

Передаточная функция
:   \(T(k)\) — подавление мод, вошедших под горизонт до равенства; аппроксимации BBKS и Эйзенштейна–Ху. См. [гл. 18](../part4-perturbations/18-lss.md).

σ₈
:   Среднеквадратичный линейный контраст плотности в шаре радиуса \(8\,h^{-1}\) Мпк при \(z = 0\); Planck: 0.811. См. [гл. 18](../part4-perturbations/18-lss.md).

Барионные акустические осцилляции
:   Отпечаток звукового горизонта \(r_d \approx 147\) Мпк в распределении галактик; стандартная линейка. См. [гл. 18](../part4-perturbations/18-lss.md).

Сферический коллапс
:   Модель нелинейного коллапса сверхплотной сферы; критический линейный контраст \(\delta_c \approx 1.686\), \(\Delta_{\rm vir} = 18\pi^2\). См. [гл. 18](../part4-perturbations/18-lss.md).

Функция масс Пресса–Шехтера
:   Число гало на единицу массы и объёма \(\d n/\d M\), выведенное из гауссовой статистики и \(\delta_c\). См. [гл. 18](../part4-perturbations/18-lss.md).
