# ОТО и космология

Учебник-хендбук для студентов 3–4 курса и старше. Предполагается знакомство с
классической механикой, электродинамикой, основами СТО и линейной алгеброй.
Тензорный анализ вводится с нуля.

## Как устроен учебник

| Часть | Содержание |
|---|---|
| [I. Математический аппарат](part1-math/index.md) | СТО в 4D-форме, многообразия, тензоры, связность, кривизна |
| [II. ОТО](part2-gr/index.md) | Принцип эквивалентности, уравнения Эйнштейна, Шварцшильд, ЧД, гравволны |
| [III. Космология FRW](part3-cosmology/index.md) | Метрика FLRW, уравнения Фридмана, расстояния, термоистория, нуклеосинтез |
| [IV. Возмущения, CMB, инфляция](part4-perturbations/index.md) | Инфляция, теория возмущений, реликтовое излучение, структура |

## Элементы глав

!!! definition "Определение"
    Новые понятия выделены такими блоками.

!!! theorem "Утверждение"
    Ключевые результаты и теоремы.

??? question "Задача"
    В конце каждой главы — задачи. Решения скрыты в раскрывающихся блоках.

Кроме того, в главах есть **интерактивные демонстрации** и **примеры на Python**
(`numpy`, `scipy`, `astropy`), которые можно скопировать и запустить.
